Learn the basics

        

          
What is steganography?

          
Steganography hides the existence of a message inside another file. SecretPixel uses the Least Significant Bit (LSB) technique: it changes the last bit of selected colour-channel values. These tiny changes are generally invisible to the eye.

          
How SecretPixel works

          
  1. Choose an image and write a message.
  2. Optionally encrypt the message using AES-GCM and a password-derived key.
  3. SecretPixel writes a small format header and message bits into RGB pixel channels.
  4. The receiver uploads the unchanged PNG and extracts the data.

          
Important limitations
Do not resize, crop, edit, screenshot, or send through services that recompress the image. These operations can destroy LSB data. Steganography is not a substitute for secure file transfer. Password protection encrypts message contents, but does not hide the fact that an image may contain data from forensic analysis.

          
Privacy
The app has no server, account, analytics, or database. Image processing happens in your browser. Do not use it to conceal illegal activity or share information without permission.
